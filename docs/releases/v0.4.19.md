## rgctl v0.4.19

Live `serve --watch` + queued `update`; grouped CLI help and `security` parent; `rgctl review` for PR call-path review and policy gates; leaner agent skill pack.

```bash
rgctl --version
rgctl --help   # Lifecycle · Query · Analysis · Security · Policy · Meta

# Live session: watch sources, refresh without stopping the watcher
rgctl serve --watch --open
rgctl -f json update                    # enqueues when watch holds the lock
rgctl -f json status                    # index_current, watcher_alive, queue depth

# PR call paths before/after (#106)
rgctl -f json review paths --base-ref origin/main --head-ref HEAD --full-snapshots

# Temporal policy gate (prefer review check; pr-check still works)
rgctl -f json review check --policy-file rgctl-pr-policy.json \
  --base-ref origin/main --head-ref HEAD --strict
```

## Highlights

### `serve --watch` + update queue

Long-lived sessions can keep the structural graph warm without full rediscover:

| Command | Role |
|---------|------|
| `rgctl serve --watch` | Debounced FS watcher → incremental compact (sole writer via `.rgctl/watch.lock`) |
| `rgctl update` | One-shot incremental patch; **enqueues** when a live watcher holds the lock |
| `rgctl status` | `index_current`, dirty counts, `watcher_alive`, queue depth |

- Watcher drains `.rgctl/update_queue.jsonl`, coalesces with FS debounce, writes per-request results under `.rgctl/update_results/`.
- Default CLI wait; `--no-wait` / `--wait-timeout` (or `RGCTL_UPDATE_WAIT_TIMEOUT_SECS`) for agents.
- Second `serve --watch` still rejected; `--force` rejected while a live watcher is elected.
- Guide: [Watch mode](../guides/watch-mode.md).

**Behavior note:** `rgctl update` during watch no longer fails with “lock held” — it enqueues (and waits by default).

### CLI help IA + `security` parent

- Grouped top-level `--help`: **Lifecycle · Query · Analysis · Security · Policy · Meta**.
- Soft namespace: `rgctl security {vuln,deps,taint}`; top-level `vuln` / `deps` / `taint` remain.
- Discover help headings: paths & filters vs pipeline features vs migration.
- Skill / encyclopedia / workflows prefer canonical verbs (`find`, `update`, `slice`, `review …`); aliases documented.

### `rgctl review` — PR call paths + gate ([#106](https://github.com/sshaaf/rgctl/issues/106))

```text
rgctl review paths   …   # before/after call-path report
rgctl review check   …   # temporal policy / CI gate
rgctl pr-check       …   # compatibility alias → review check
```

**`review paths`**
- Seeds: hunk-scoped functions/methods ∪ Calls edge-delta endpoints ∪ base-only deletes.
- Per symbol: `path_before` / `path_after` representative spines, `path_delta` (`added` / `removed` / `retargeted`), truncation flags, `unscored_files`.
- JSON: `schema_version: 1`, `command: "review paths"`. Truncation exits **0**; ambiguous `--symbol` lists candidates and exits **2**.
- Depths: `--upstream-depth` (default 2), `--downstream-depth` (default 1); caps `--fanout` / `--max-symbols`.

**`review check` / `pr-check`**
- Same policy JSON (`schema_version: "2"`) and exit-code semantics as before.
- Shared base/head artifact prep with `review paths`.

See [JSON API §8b–8c](../json-api.md#8b-review-check--pr-check).

### Agent skill pack (token lean)

- Trimmed `SKILL.md` / workflows / encyclopedia for lower context when the skill loads.
- Removed leftover per-workflow skill stubs under `skills/rgctl/workflows/` (single `rgctl` skill + `references/` remains the pack).
- README / docs: GQL leftovers cleaned up; structured verbs stay primary.

### Reliability

- Kantra / status-path fixes; columnar spill / content-store hardening alongside the Kantra signal-fault fix.

## Breaking / migration notes

| Change | Action |
|--------|--------|
| `update` under `serve --watch` | Expect enqueue/wait (or `--no-wait`), not a lock error |
| Prefer `review check` | Update CI/docs; keep `pr-check` scripts as-is |
| Help layout | Visual only; argv unchanged except new `review` / `security` parents |
| Skill pack | Re-run `rgctl install --skill --tools …` if you want the leaner pack on disk |
