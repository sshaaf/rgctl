## rgctl v0.4.18

OSV → deps → reachability → OpenVEX end-to-end; declarative multi-language taint rules; agent pack on structured query verbs (no GQL skills / no `--with-commands`); ingest hot-path + constrained discover; ERB Tier‑1.

```bash
rgctl --version
# Vuln path (index with CFG for sink-first / VEX confidence):
cd "$REPO" && rgctl discover . --with-cfg --with-taint
rgctl -f json vuln triage --osv ./advisory.json
rgctl -r "$REPO" -f json deps check --osv ./advisory.json --include-jars lib
rgctl -r "$REPO" -f json vuln analyze --osv ./advisory.json --include-jars lib
rgctl -r "$REPO" -f json taint --sink ObjectMapper.readValue --source external
```

## Highlights

### OSV supply chain → reachability → OpenVEX ([#102](https://github.com/sshaaf/rgctl/pull/102))

End-to-end agent path:

```
vuln triage → deps check → find/callers --package → blast-radius --classify-boundary
  → taint --sink … --source external → vuln analyze → OpenVEX
```

**Deps / triage (`add-osv-deps-supply-chain`)**
- `rgctl vuln triage --osv` — parse via the `osv` 0.3 schema crate.
- `rgctl deps check --osv` — manifests + opt-in `--include-jars` / `--include-node-modules`.
- Version engines: Maven (incl. `-rhlw-` backports), Cargo, npm, Go.
- Verdicts: `not_affected` | `affected_candidate`.

**Declarative taint (`add-declarative-taint-rules`, [#16](https://github.com/sshaaf/rgctl/issues/16))**
- `TaintRuleSet` loads YAML packs (Tier‑1 under `crates/rgctl-analysis/rules/taint/`); hardcoded `detect_*_patterns` removed.
- CWE catalog YAML; `--taint-rules` + `.rgctl/taint-rules.d/` overlays (built-in < project < CLI); OSV sink overlays via `with_overlays`.
- Discover-time taint remains **opt-in** (`--with-taint`).

**Reachability / OpenVEX (`add-vuln-reachability-vex`)**
- Package resolver (Maven/npm/Cargo/Go/PyPI + stubs): `find` / `callers --package`, `callers --methods`, `bundled_presence` honesty.
- **Xalan dual path:** `xalan:*` → Apache prefixes **and** JDK JAXP aliases (`javax.xml.transform`, `com.sun.org.apache.xalan.internal`) with `runtime_bundled=true`.
- Boundary catalogs (Java/Jakarta + Python); `blast-radius --classify-boundary`.
- Sink-first `rgctl taint --sink … --source external` (CFG required).
- `rgctl vuln analyze --osv …` → OpenVEX (`openvex` crate).
- CoolStore live gate: **7/7 native** probes; Xalan fast-exit `component_not_present`; Jackson full pipeline `vulnerable_code_not_in_execute_path` (~46ms analyze on warm session).

**Agent guidance:** for vuln / sink-first / VEX beyond deps-only, index with `discover . --with-cfg` (add `--with-taint` for PDG-backed confidence). See skill `references/workflows.md` and [json-api §18](../json-api.md).

### Agent pack: structured verbs, single skill ([#102](https://github.com/sshaaf/rgctl/pull/102))

- Prefer mmap structured verbs: `find` / `callers` / `relations` / `inventory` / `status` / `rules run`.
- **Removed** GQL from skills and the agent pack surface; **dropped** `rgctl install --with-commands` (skills + optional `--with-policy` only; install JSON `schema_version` 3).
- Migration probes: `find --annotation`, `inventory --by import-prefix`, `rgctl status`, `rgctl resources`, `rgctl rules run`.
- One installable `rgctl` skill tree (`references/workflows.md` covers vuln, kantra, migrate, …).

### Ingest hot path + constrained discover

- Hash reuse on extract workers; empty-tracker short-circuit; spill scratch + `serialize_into`; pass-1 file batches; `&str` bodies / worker `SymbolPass1Prep`; tracker mapping at commit; CodeIndex bodies off by default.
- Opt-in constrained discover: `--with-limits max-mem-mb=…,threads=…` / `RGCTL_WITH_LIMITS` (soft RSS tripwire; smaller spill runs) — defaults unchanged for desktop.
- Release tooling: `./scripts/bump-version.sh`, `cargo release` / `release.toml`.

### ERB ([#101](https://github.com/sshaaf/rgctl/pull/101))

- Tier‑1 **ERB** plugin (`tree-sitter-embedded-template`); theforeman corpus for Puppet+ERB cold profile smoke.

## Breaking / migration notes

- **Agent pack:** delete leftover `rgctl-discover` / `rgctl-*` workflow skill dirs and any `.cursor/commands/` stubs from older installs; re-run `rgctl install --skill --tools cursor` (no `--with-commands`).
- **Vuln confidence:** plain `discover` is enough for triage + deps-only early exit; reachability / sink-first / firm VEX needs `discover --with-cfg` (prefer `--with-taint` too).
- **Taint rules:** customize via YAML packs / overlays — not in-tree `detect_*` Rust pattern tables.
