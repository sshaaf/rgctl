## rgctl v0.4.13

**Temporal PR gate + installed-binary dashboard fix** — delta `pr-check`, violation ledger, and recursive extraction of embedded dashboard assets when `dashboard/dist` is not on disk.

```bash
rgctl --version
./scripts/build-dashboard.sh && cargo build --release
```

## Highlights

### Dashboard

- Recursively validate and extract embedded `dashboard/dist` (fixes `dashboard_ready: false` on installed binaries; nested `assets/` are included)

### Graph / CI policy

- **Deterministic node IDs:** `Node.id` from `StableNodeKey` + UUID v5 when a file path is set. **Migration:** delete `.rgctl` / `.rgctl-base` and run `rgctl discover .` once (see [CI Policy Checks](../guides/ci-policy-checks.md#one-time-setup)).
- **Delta `pr-check` head:** default synthesizes head from base artifact + git delta; `--full-snapshots` for dual full discover.
- **Violation timeline:** `pr-check` JSON schema v2, `violations_summary`, regression class, `--bisect`, `--synthetic-head worktree`, `.rgctl/violation_ledger.jsonl`; `check --temporal`.
- **Calendar policies:** optional `temporal` block with `--strict-calendar`.
