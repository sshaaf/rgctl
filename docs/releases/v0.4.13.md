## rgctl v0.4.13

**Installed-binary dashboard fix** — embedded `dashboard/dist` is extracted recursively so nested `assets/` (JS, CSS, WASM) work when the source tree is not present.

```bash
rgctl --version
./scripts/build-dashboard.sh && cargo build --release
```

## Highlights

### Dashboard (stable)

- Recursively validate and extract embedded `dashboard/dist` (fixes `dashboard_ready: false` and placeholder UI on release binaries; issue #83)

### Temporal PR gate (preview)

The following ship in **v0.4.13 for early adopters**; APIs, defaults, and docs may change until the temporal gate is finalized. Prefer `check` for production CI until you have reviewed [CI policy checks](../guides/ci-policy-checks.md).

- **Deterministic node IDs:** `Node.id` from `StableNodeKey` + UUID v5 when a file path is set. **Migration:** delete `.rgctl` / `.rgctl-base` and run `rgctl discover .` once.
- **Delta `pr-check` head:** default synthesizes head from base artifact + git delta; `--full-snapshots` for dual full discover.
- **Violation timeline (preview):** `pr-check` JSON schema v2, `violations_summary`, regression class, `--bisect`, `--synthetic-head worktree`, `.rgctl/violation_ledger.jsonl`; `check --temporal`.
- **Calendar policies (preview):** optional `temporal` block with `--strict-calendar`.
