## rgctl v0.4.11

**Extraction depth across Tier 1 languages** — richer graph edges (`Import`, `EXTENDS`, `IMPLEMENTS`, `ANNOTATEDWITH`, `INSTANTIATES`, qualified calls) for Rust, C, C++, TypeScript, JavaScript, C#, and Python, plus discover/CFG performance work and a per-language GQL verification smoke suite.

```bash
rgctl --version
RGCTL_SKIP_EXAMPLE=1 ./rgctl-tests/gql-verification-smoke/run-all-extraction-gql.sh
```

## Highlights

### Extraction depth (Tier 1 plugins)

| Language | New / improved graph extraction |
|----------|----------------------------------|
| **Rust** | `use` → `Import`/`Module`; trait `Interface` + `Implements`; `#[attr]` → `AnnotatedWith`; crate-qualified call FQNs; `Instantiates` / `References` |
| **C** | `#include` graph; `file::symbol` qualified names; call resolution on ecommerce + Linux scale |
| **C++** | `EXTENDS` inheritance; `INSTANTIATES` (`new` / templates); qualified call hints; LLVM `clang/` cold-profile gate |
| **C#** | Namespace FQN; `ANNOTATEDWITH` on types/members; `INSTANTIATES`; custom call binding with `using` map; records/delegates metadata |
| **TypeScript** | Module graph; `EXTENDS` / `IMPLEMENTS`; decorators; iterative tree walks (no recursive overflow) |
| **JavaScript** | ESM/CJS imports; class heritage; decorators; method FQN; iterative tree walks |
| **Python** | `import` / `from … import`; `EXTENDS`; decorators; `INSTANTIATES`; `OrderService.*` method FQN |

Shared helpers live in `crates/rgctl-plugin-helpers` (Python/JS patterns) and per-language `extract_depth` modules. Langfeatures integration tests: `tests/{rust,c,cpp,csharp,javascript,typescript,python}_langfeatures.rs`.

### GQL verification smoke (`rgctl-tests/gql-verification-smoke/`)

Per-language scripts verify extraction-depth GQL probes **and** core commands (`blast-radius`, `metrics`, `inspect`, `slice`, `cpg`, `semantic`, `export`, `check`) against each `ecommerce-*` fixture:

```bash
cargo build --release --bin rgctl
RGCTL_SKIP_EXAMPLE=1 ./rgctl-tests/gql-verification-smoke/run-all-extraction-gql.sh
```

Ten languages: C, C++, C#, Go, Java, JavaScript, PHP, Python, Rust, TypeScript.

### Discover & CFG performance

- **Parallel field-write index** (`with_large_pool`)
- **Analysis packfile** — replaces per-function spill files; CFG/PDG archive v2 TOC
- **Graph memory** — lazy property maps, streaming query/export, adjacency-list edge lookup, removed ~100MB lazy UUID HashMap on mmap
- **Centrality** — parallel sampled betweenness (rayon + per-thread Brandes scratch); CSR adjacency for neighbor iteration
- **Hot-path allocations** — `StringInterner` collapse, spill sort with fixed keys + rayon, parallel node/edge compaction
