## rgctl v0.4.14

**Agent pack install** and **Ruby (Tier 1)** — multi-tool workflow skills, slash commands, and full graph/CFG/taint support for Ruby codebases.

```bash
rgctl --version
rgctl install --skill --with-commands --tools cursor,claude,codex,agents
rgctl discover . -l ruby -e vendor,tmp,node_modules --with-cfg
```

## Highlights

### Agent pack

- **`rgctl install`** — `--skill`, `--with-commands`, `--with-policy`, `--tools` / `all`, `-g`, `--list-agents`, `--force`; JSON **`schema_version`: 2**.
- **Workflow skills** — `rgctl-discover`, `rgctl-impact`, `rgctl-flow`, `rgctl-search`, `rgctl-gql`, `rgctl-migrate`, `rgctl-kantra`, `rgctl-gate` plus meta skill `rgctl`.
- **Registry** — ~40 adapters in `agent-pack/agents/registry.toml` (Cursor, Claude, Codex, OpenCode, Pi, Copilot, Antigravity, Gemini CLI, …).
- **Workflow docs** — single source in `skills/rgctl/workflows/`; `references/workflows.md` assembled at build.
- **`--host`** deprecated in favor of **`--tools`** (warning on use).
- **Codex** skill installation support ([#79](https://github.com/sshaaf/rgctl/pull/79)).

### Ruby (Tier 1)

- New plugin **`rgctl-lang-ruby`** (`tree-sitter-ruby`) — classes, modules, methods, `require` graph, mixin edges (`include` / `prepend` / `extend`), calls, `.new` instantiation, constructor metadata.
- **CFG / PDG / taint** enabled for Ruby; ivar def-use and Rails-style patterns in taint analysis.
- **Graph resolution** — method QNs with `#` / `.`; suffix index for call targets; mixin scope fixes for accurate `EXTENDS` edges.
- **CPG / field writes** — `@ivar` mutations and `cpg mutations --type YourModel` when receiver typing uses Ruby method FQNs (`Type#method`).
- **Verification** — `rgctl-tests/ecommerce-ruby`, langfeatures fixtures, optional cold-profile gate on `example/discourse`.
- Docs: [Ruby language guide](../languages/ruby.md), [extract honesty](../ruby-extract-honesty.md).
