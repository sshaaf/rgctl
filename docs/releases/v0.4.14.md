## rgctl v0.4.14

**Agent pack install** — multi-tool workflow skills, slash commands, optional policy, and OpenSpec-aligned adapter registry.

```bash
rgctl --version
rgctl install --skill --with-commands --tools cursor,claude,codex,agents
```

## Highlights

### Agent pack

- **`rgctl install`** — `--skill`, `--with-commands`, `--with-policy`, `--tools` / `all`, `-g`, `--list-agents`, `--force`; JSON **`schema_version`: 2**.
- **Workflow skills** — `rgctl-discover`, `rgctl-impact`, `rgctl-flow`, `rgctl-search`, `rgctl-gql`, `rgctl-migrate`, `rgctl-kantra`, `rgctl-gate` plus meta skill `rgctl`.
- **Registry** — ~40 adapters in `agent-pack/agents/registry.toml` (Cursor, Claude, OpenCode, Pi, Copilot, Antigravity, Gemini CLI, …).
- **Workflow docs** — single source in `skills/rgctl/workflows/`; `references/workflows.md` assembled at build.
- **`--host`** deprecated in favor of **`--tools`** (warning on use).
