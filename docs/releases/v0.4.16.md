## rgctl v0.4.16

Stable extension digests for snapshot diff (#93), a new `rgctl diff` compare command with linux cold-diff profiling, and docs that describe the agent pack as meta + workflow skills + slash commands.

```bash
rgctl --version
rgctl -f json diff --base path/to/base --head path/to/head
RUST_LOG=info,profile=info rgctl -f json diff \
  --base example/linux/.rgctl-diff/base \
  --head example/linux/.rgctl-diff/head
```

## Highlights

### Snapshot diff digests (#93)

- **`extension_digest` is deterministic** for identical multi-property nodes. `LazyStringMap` still uses `HashMap` for ingest, but serializes keys in sorted order (stack sort for ≤8 props).
- Stops `diff_snapshots` / `pr-check` from reporting spurious **`Changed`** nodes when nothing changed (HashMap `RandomState` order).
- Zero-copy write path via `NodeExtensionRef`; legacy unsorted extension blobs still deserialize.
- Fixes [#93](https://github.com/sshaaf/rgctl/issues/93) via [#94](https://github.com/sshaaf/rgctl/pull/94).

### `rgctl diff` + cold-diff profile

- New **`rgctl diff --base/--head`** — open a snapshot pair, compare digests, run `diff_snapshots` (noop sink), emit stats and `[profile] diff summary`.
- Prep script **`./scripts/prepare-linux-diff-snapshots.sh`** (default **v7.1** vs **HEAD**) and ignored gate **`linux_cold_diff_within_baseline`**.
- Documented in [`docs/internal/profile.md`](../internal/profile.md) and [`AGENTS.md`](../../AGENTS.md). Separate from cold discover. Future: unify with `pr-check` under one `diff` surface ([#95](https://github.com/sshaaf/rgctl/issues/95)) without thinning the policy gate.

### Docs / website

- Agent pack described as **meta skill + eight workflow skills + slash commands** (not a single skill): website Agents/Install pages, [`agent-commands`](../guides/agent-commands.md), [`agent-skill`](../guides/agent-skill.md) walkthrough.
- Deny-comment docs clarification ([#92](https://github.com/sshaaf/rgctl/pull/92)).
